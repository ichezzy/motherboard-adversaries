# White Signal — Gegner

Foundry-VTT-Modul (Version 14, System Daggerheart 2.12.9) mit allen Gegnern und Umgebungen der Kampagne *White Signal* als Kompendium.

## In Foundry installieren

1. Foundry-Setup → **Add-on Modules** → **Install Module**.
2. Unten bei **Manifest URL** einfügen:
   `https://github.com/ichezzy/white-signal-gegner/releases/latest/download/module.json`
3. **Install** klicken, dann in der Welt unter **Manage Modules** „White Signal — Gegner“ aktivieren.

Das Kompendium „White Signal — Gegner“ sehen nur Spielleitung und Assistenz.

## Neu bauen und veröffentlichen

- **`Gegner bauen.bat`** – baut das Modul nur auf diesem PC und zeigt, was neu ist und was sich geändert hat. Nichts wird hochgeladen.
- **`Gegner veröffentlichen.bat`** – baut, zeigt die Zusammenfassung, fragt nach und lädt dann eine neue Version auf GitHub hoch. Die Versionsnummer zählt dabei automatisch hoch.

Danach in Foundry: Setup → Add-on Modules → **Nach Updates suchen** → bei „White Signal — Gegner“ **Aktualisieren**.

Pfade und Varianten (z. B. Dreiklaue) stehen in `einstellungen.json`.
